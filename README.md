# sashaqi.github.io

Personal site. Hugo + [PaperMod](https://github.com/adityatelange/hugo-PaperMod),
published automatically from the `05-Public` folder of a private Obsidian vault.

Same stack as [lilianweng.github.io](https://lilianweng.github.io).

## Layout

```
hugo.yaml                    site config
content/archives.md          Archive page (PaperMod special layout)
content/search.md            Search page (Fuse.js index)
content/posts/               generated by sync_vault.py — gitignored
scripts/sync_vault.py        Obsidian → Hugo converter
scripts/dev.sh               local sync + preview
.github/workflows/deploy.yml build and deploy
docs/SETUP.md                one-time wiring
```

## Local development

```bash
./scripts/dev.sh
```

Set `VAULT_PATH` if the vault isn't at the default iCloud location.

## Publishing

Write in Obsidian under `05-Public/`. obsidian-git pushes the vault, which
fires a `repository_dispatch` here, which rebuilds and deploys. See
[docs/SETUP.md](docs/SETUP.md).
